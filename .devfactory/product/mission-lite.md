# CPA Bot - Mission Summary

## Pitch
CPA Bot is a personal financial assistant that helps individuals resolve IRS tax debt, manage finances, and optimize taxes year-round through intelligent automation and AI-powered insights.

## Primary User
**Johnny5** - Wisconsin-based individual with outstanding IRS tax debt from a previous company, potential 1099 work, and need for year-round tax planning. Technical background in Next.js/FastAPI/Supabase.

## Core Problem
IRS tax debt resolution is complex and expensive ($3K-$15K for professional help). Individuals lack tools to calculate Offer in Compromise eligibility, compare relief programs, or manage the resolution process themselves.

## Solution
A comprehensive personal CPA assistant providing:
1. **IRS Debt Resolution Tools** - OIC calculator, payment plan comparison, deadline tracking
2. **Automated Financial Tracking** - Plaid-connected bank sync with AI categorization
3. **Cash Flow Forecasting** - Know what comes in when, what goes out when, and where you'll be at month-end
4. **Tax Planning** - Year-round projections, deduction tracking, optimization
5. **Document Management** - OCR processing and organization of tax documents

## Top 6 Features
1. **OIC Calculator** - Full RCP calculation (assets + age-adjusted future income + disposable income)
2. **Relief Program Comparison** - OIC vs Installment Agreement vs CNC with strategy recommendations
3. **Plaid Bank Integration** - Automatic transaction sync with Claude-powered categorization
4. **Cash Flow Forecasting** - Recurring pattern detection, projected balances, month-end predictions from any point
5. **Tax Projection Engine** - Federal + Wisconsin state calculations, standard vs itemized
6. **IRS Correspondence Tracker** - Deadline management, document storage, response tracking

## Key Differentiator
Democratizes access to IRS debt resolution analysis (normally $5K+ from tax resolution firms) while providing year-round AI-powered financial intelligence—purpose-built for individuals, not businesses.

## Tech Stack
Next.js 14 (full-stack) + Supabase + Vercel + Plaid API + Claude API

## Safety Note
Tool provides information/organization, not professional tax advice. Recommends professional help for debt >$50K, business taxes, or complex situations.
